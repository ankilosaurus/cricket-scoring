# Cricket Scorer 🏏

Simple ball-by-ball cricket scoring web app.

## Features

- Set up teams and overs (1–20)
- Score runs (0–6), wickets, wides, no-balls, byes, leg-byes
- Live score, overs, run rate
- Chase target in second innings
- Auto-detect match result
- Undo last ball
- Persists in browser (localStorage)

## Tech

- Next.js 14 (App Router)
- React 18
- TypeScript
- Client-side only (no backend)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deployed on Vercel.
